## What I Improved

| Area | Improvement |
|---|---|
| Realtime | WebSocket UPDATE payload `1,028B -> 361B`, 약 64.9% 감소 |
| Upload | 15MB 영상 파일이 Spring API 본문을 직접 거치지 않도록 MinIO presigned URL 구조 적용 |
| Auth | Redis refresh token session, access token blacklist로 로그아웃 이후 토큰 재사용 차단 |
| CI/CD | Jenkins clean build `17.81s -> 11.93s`, 약 33.0% 단축 |
| Finalization | 릴레이 결과 생성 흐름을 scheduler 의존에서 이벤트 기반 비동기 트리거로 개선, 정상 경로 최대 10초 단축 |
| Query | 관리자 신고 필터 조회 p95 응답시간 개선 및 PostgreSQL partial index 적용 |
